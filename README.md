## Предметная область

В автосервисе хранятся сведения о клиентах, их автомобилях, механиках, видах работ и заказах.

- **Person** — базовый класс для клиента и механика: идентификатор и ФИО.
- **Client** — клиент: телефон; одному клиенту может принадлежать несколько автомобилей.
- **Car** — автомобиль: госномер, марка, модель, год выпуска и владелец.
- **Mechanic** — механик: номер паспорта, специализация (`Specialization` — перечисление) и стаж работы.
- **WorkType** — вид работ: название, категория, стоимость и продолжительность.
- **Order** — заказ: автомобиль, клиент, механик, список видов работ, даты приёма и выдачи автомобиля.

## Структура решения

- `src/AutoService.Domain` — классы предметной области.
- `tests/AutoService.Tests` — unit-тесты на xUnit v3 с данными в памяти: 10 клиентов, 12 автомобилей, 10 механиков, 12 видов работ и 28 заказов.

MySQL и gRPC предусмотрены вариантом для следующих лабораторных работ. В первой работе данные хранятся в памяти.

## Реализованные запросы (unit-тесты)

1. Механики, специализирующиеся на выбранном виде работ.
2. Клиенты, чьи автомобили обслуживались у указанного механика, упорядоченные по ФИО.
3. Количество повторных обращений клиентов за последний месяц.
4. Суммарная стоимость работ для выбранного заказа.
5. Топ-5 наиболее частых видов работ.

## Запуск тестов

Нужен .NET 10 SDK. Из корня репозитория:

```shell
dotnet test AutoService.slnx
```

Тесты также выполняются автоматически в GitHub Actions при каждом push и pull request.
